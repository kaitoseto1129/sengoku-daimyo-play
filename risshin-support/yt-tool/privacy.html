Privacy Policy — Sengoku Risshin YouTube Uploader

最終更新：2026年10月24日 / Last updated: October 24, 2026
運営者：瀬戸海斗（個人） / Operator: Kaito Seto (individual)

1. YouTube API Services の利用 / Use of YouTube API Services

「戦国立身 YouTube 投稿ツール」（以下「本ツール」）は YouTube API Services を使っています。本ツールを使う人は、YouTube 利用規約（https://www.youtube.com/t/terms）に同意したものとみなします。Google による情報の扱いは Google プライバシーポリシー（https://policies.google.com/privacy）をご覧ください。

The Sengoku Risshin YouTube Uploader (the "Tool") uses YouTube API Services. By using the Tool, you agree to be bound by the YouTube Terms of Service (https://www.youtube.com/t/terms). For how Google handles your data, see the Google Privacy Policy (https://policies.google.com/privacy).

2. 集める情報 / Information we access and collect

本ツールは、運営者本人が Google の OAuth で許可した時に、運営者自身の YouTube チャンネルについて次の情報を YouTube API Services から読み書きします。

  • OAuth のトークン（アクセストークンと更新トークン）
  • 自分のチャンネルの ID・名前・登録者数（channels.list）
  • 自分が上げた動画の ID・題・説明・タグ・公開予定日時・サムネイル・再生数・高評価数・コメント数（videos.list）
  • 自分の再生リストとその中の動画（playlists・playlistItems）
  • 自分の動画に付いた公開コメント（投稿者の表示名とコメント本文。commentThreads.list）

ほかの人の Google アカウントへの許可は求めません。名前・メールアドレス・住所・支払いの情報は集めません。広告や行動の追跡（クッキー・解析タグ）は使いません。

When the operator authorizes the Tool through Google OAuth, the Tool reads and writes the following data about the operator's own YouTube channel via YouTube API Services: OAuth tokens (access and refresh tokens); own channel ID, name and subscriber count (channels.list); own videos' IDs, titles, descriptions, tags, scheduled publish times, thumbnails, and view/like/comment counts (videos.list); own playlists and playlist items; and public comments on own videos, including the commenter's display name and comment text (commentThreads.list). The Tool does not request authorization from any other Google account, and does not collect names, e-mail addresses, postal addresses or payment information. It uses no advertising, cookies or analytics tracking.

3. 使い方 / How we use the information

集めた情報は、次の目的だけに使います：自作の動画の予約投稿、題・説明・サムネイルの差し替え、再生リストへの追加、自分の動画の数（再生数など）を手元の画面で見て次に作る動画を決める事、自分の動画へのコメントに返事をする事。情報を売ったり、第三者に渡したり、広告に使ったりはしません。

The information is used only to: schedule uploads of the operator's own original videos; update their titles, descriptions and thumbnails; add them to playlists; view the operator's own video statistics on a local dashboard to plan future videos; and reply to comments on the operator's own videos. We do not sell, share with third parties, or use the information for advertising.

4. 保存 / Storage

更新トークンは運営者のパソコンの中だけに、本人しか読めないファイル（権限 600）として保存します。動画の数の記録は同じパソコンの中のファイルに保存し、外のサーバーには送りません。YouTube から得た数は、最大 30 日で最新の物に入れ替えるか消します。

The refresh token is stored only on the operator's own computer, in a file readable only by the operator (permission 600). Video statistics are stored in local files on the same computer and are never sent to any external server. Data obtained from YouTube API Services is refreshed or deleted within 30 days.

5. 消し方と許可の取り消し / Deletion and revoking access

本ツールへの許可は、いつでも Google アカウントの許可の設定 https://security.google.com/settings/security/permissions から取り消せます。取り消すと、本ツールは YouTube のデータを読めなくなります。手元に残った情報（トークンと数の記録）の削除を望む時は、下の連絡先にご連絡ください。7 日以内に消します。許可を取り消した時も、手元の情報は 7 日以内に消します。

You can revoke the Tool's access at any time via the Google security settings page at https://security.google.com/settings/security/permissions. After revocation, the Tool can no longer access YouTube data. To request deletion of locally stored data (tokens and statistics records), contact us at the address below; we will delete it within 7 days. Locally stored data is also deleted within 7 days after access is revoked.

6. 変更 / Changes

このポリシーを変える時は、この頁の最終更新日を改めます。

If this policy changes, the "Last updated" date on this page will be revised.
